# Changelog

## 0.1-beta (first public beta)
- In-game volume bar "System sounds" as a fourth row of the config menu (Menu → Quit/Config)
- 10 steps of 3 dB (0 = mute, 10 = original), stored in the save data, default step 6 (−12 dB)
- Texts in English, German, French and Japanese
- Backup/restore of the EXE and all text files
- `report` command (key **B**) for beta testers, `--allow-unknown` for compatible unknown builds
